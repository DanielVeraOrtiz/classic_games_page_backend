# 🟢 Backend - Classic Games Platform

API REST desarrollada con Node.js y Koa que gestiona autenticación de usuarios y persistencia de favoritos.

---

## 🚀 Deploy

🔗 https://classic-games-page-backend.onrender.com

---

## 🛠️ Tecnologías

- Node.js
- Koa
- Sequelize
- PostgreSQL
- JWT

---

## 🔐 Autenticación

La API utiliza JSON Web Tokens (JWT) para proteger rutas.

El token debe enviarse en el header. En Authorization como Bearer {token}.

## 🧪 Testing

La API cuenta con testing de integración utilizando:

- Jest
- Supertest
